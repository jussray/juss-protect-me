# Agent Instructions

## One Cohesive Cinematic Composition — Portfolio Standard (2026-11-04)

All authorized AI agents and contributors must treat every app, page, site and screen as **one cohesive cinematic composition**. Create one deliberate focal hierarchy, atmosphere and continuous visual language across layout, typography, lighting, imagery, depth, navigation, interactions and all relevant states. No disconnected collage of cards or generic template substitutions.

Preserve the individual product's canonical colors, visual identity, trust requirements, users, content, functional behavior, and privacy/security boundaries. Inspect actual source, design tokens, routes and live/rendered evidence before changing the UI. Include responsive mobile, keyboard, focus visibility, semantic markup, contrast, reduced motion, loading, empty and error behavior. Never prioritize spectacle over accessibility or real functionality.

For actual UI changes, verify screenshots and interactions on the exact candidate branch/head and record tests, evidence gaps, rollback, release status and remaining gates. Policy text is not proof of an implemented or deployed redesign. Do not infer permission to merge, deploy, publish, spend, delete or expose private data.
